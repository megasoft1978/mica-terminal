Every project gets its own terminal.

Mica is a native Mac terminal that keeps a project’s shells and coding agents together, and shows you when one of them needs you.

Build Mica View source on GitHub

macOS 14 or later. Free and open source. No packaged download yet.

This is the real Mica view, rendered from a sample project. Switch themes any time with ⌥⌘L.

Build it in four commands.

You need the Xcode command line tools and Homebrew. Mica links its one C dependency into the app, so the finished bundle runs on its own.

# the terminal parsing library brew install libvterm pkg-config git clone https://github.com/megasoft1978/mica-terminal.git cd mica-terminal make app && open build/Mica.app

One window for each project.

Name a project, give it folders and startup tabs, and open it again from a launcher on your Desktop. Its Dock icon carries a short mark of the project name, so you can tell windows apart at a glance.

Agents are ordinary programs.

Run Codex, Claude Code or anything else in a normal zsh tab. Mica watches the tab and shows whether the program is working or waiting for you, so you can look away until it asks. Your own zsh configuration keeps working.

Speak, then read it back.

Hold left ⌥, say what you want to run, and release. Your words appear in the prompt for you to edit before you press Return. Recognition runs on your Mac; the first use downloads a 630 MB speech model.

A focus timer that follows you.

One timer is shared by every Mica window on your Mac, with a notification when a focus or break period ends. It lives in the status bar, so it never covers your output.

Still your terminal.

Search what scrolled by with ⌘F, open links with ⌘-click, drag tabs to reorder them, and paste images for agents that read them. When a program on a remote machine asks to set your clipboard, Mica asks you first.

Build Mica Releases

Mica uses AppKit and a C session core, with libvterm (MIT) parsing terminal output and JetBrains Mono (SIL OFL 1.1) as its font. Local dictation uses FluidAudio (Apache-2.0), Apple Core ML, and Parakeet Ultra by Moondream, based on NVIDIA Parakeet TDT 0.6B v3 (CC BY 4.0). See the full notices.

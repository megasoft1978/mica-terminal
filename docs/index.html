01 / PROJECTS

A home for each project

Name a workspace, choose its folders and tabs, and open it again from a small desktop launcher.

02 / AGENTS

Know when it’s your turn

Run Codex and Claude Code in regular terminal sessions. Mica surfaces agent activity and input requests.

03 / DICTATION

Speak, then review

Hold left Option to dictate into the active shell. Speech recognition runs locally after the first model download.

04 / TERMINAL

Your shell stays yours

Interactive zsh, aliases, plugins, arbitrary commands, selectable output, and bounded scrollback you can search with ⌘F.

05 / FOCUS

A timer that follows you

Keep a shared focus and break timer across project windows, with macOS notifications at phase changes.

06 / NATIVE

Built for the Mac

A lightweight AppKit interface with a C session core and libvterm rendering. Project marks help distinguish windows in the Dock and app switcher. Three idle tabs use about 77 MiB, similar to Terminal.app running Zellij (measurements).

Built with

Good tools, clearly credited.

Mica uses AppKit for its macOS interface, a C session core, and libvterm (MIT) for terminal parsing. Local dictation uses FluidAudio 0.17.4 (Apache-2.0), Apple Core ML and AVFoundation, and Parakeet Ultra by Moondream, based on NVIDIA Parakeet TDT 0.6B v3 and distributed as a Core ML conversion by FluidInference (CC BY 4.0). See the full third-party notices. Mica source is available on GitHub; the project does not yet have a root-level license.

Get started

Build it from source.

Mica is under active development. There’s no packaged download just yet. If you have a Mac and the Xcode command line tools, you can build the app in a few commands.

Check releases for future downloads ↗
# install the terminal rendering library
brew install libvterm pkg-config
git clone https://github.com/megasoft1978/mica-terminal.git
cd mica-terminal
make app
open build/Mica.app

# Mica 0.1.0 alpha 14

This release moves the focus timer into a compact macOS menu bar extra, keeping terminal status space clear for project, command and memory context.

## New

- Show a phase symbol and countdown in the menu bar for focus, break and paused timer states.
- Click the menu bar timer to start, pause, resume or end a phase. The timer remains shared across every Mica project window.
- Keep timer controls in the **Focus** menu and announce phase, remaining time, session label and completed focus count to VoiceOver.
- Show the menu bar timer by default; hide it in **Settings**.
- Refresh the README, website, video and GIF to match the new timer placement.

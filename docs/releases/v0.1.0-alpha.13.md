# Mica 0.1.0 alpha 13

This release brings saved SSH connections to Mica alongside the latest dictation, status and agent workflow updates.

## New

- Save SSH profiles with a friendly name, OpenSSH destination and remote starting folder.
- Open a profile in a fresh interactive terminal tab and restore it with project layouts.
- Reuse macOS OpenSSH configuration, keys, agents, host-key verification and existing VPN routes. Mica does not store SSH credentials or control VPNs.
- Show a multiline live dictation preview in a reserved area above the terminal.
- Display clearer command and tool status, with recent agent activity and optional process-memory warnings.
- Restore validated Claude Code and Codex sessions when enabled; restored SSH profiles always start new connections.

## Connecting to another Mac or Linux host

Use **Session → SSH Connections…** to create profiles. Configure identities, ports, jump hosts and VPN routing in `~/.ssh/config`. Enable **System Settings → General → Sharing → Remote Login** on a Mac host. A remote folder beginning with `~/` is relative to the remote user's home folder.

For Starlink connections from outside the local network, use a route that can accept the connection, such as a VPN/overlay, reachable IPv6 or eligible public IPv4. Starlink's default IPv4 service uses CGNAT.

SSH command construction and profile restores are tested with local fixtures and a fake SSH executable; this release has not been tested against a specific remote host.

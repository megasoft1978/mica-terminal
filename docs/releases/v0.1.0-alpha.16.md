# Mica 0.1.0 alpha 16

This release rolls the recent project-window and launcher changes into one notarized build, and makes the active project easier to recognize in Mica's window and Dock.

## New

- Show the project name in the top-right window badge and include it in the window title.
- Infer project names from the Git root or working folder, and use the SSH profile name for remote sessions.
- Show the complete project name when hovering over the window badge.
- Add a Dock menu that lists each open project window by project and tab name. The single Mica process still has one Dock tile; its icon mark follows the active project.
- Open `.mica` project layouts from Finder and from managed Desktop launchers.
- Start and finish dictation from the status-bar microphone control, including in remote desktop sessions.
- Show compact Claude Code and Codex status in tabs, with full details in each tab's tooltip.
- Restrict the local agent hook socket to its owner, validate stale socket removal, and cap concurrent clients.

## Packages

- `Mica.zip` and `Mica.dmg` are Developer ID signed and notarized for Apple silicon and macOS 14 or later.
- Verify either package with the published `SHA256SUMS.txt` manifest using `shasum -a 256 -c SHA256SUMS.txt`.
